# 🙏 Happy Ganesh Chaturthi 2026

A beautiful mobile-friendly Ganesh Chaturthi greeting application created using Python and Streamlit.

## ✨ Features

- Beautiful dark devotional background
- Ganesh Ji image display
- Golden glowing design
- Floating particles
- Animated diyas
- Ganesh mantra
- Interactive blessing button
- Responsive mobile layout
- Phone-friendly presentation
- Simple and clean UI

## 🛠️ Technologies

- Python
- Streamlit
- Pillow
- HTML
- CSS
